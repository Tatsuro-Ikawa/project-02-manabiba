# Step4：満足度の理由から、こころのブレーキの入口を探る

Step3 で決めた領域について、**なぜ満足度がその点数なのか**を書き出し、「自分の何が変われば満足度が上がりそうか」を整理します。

ここで見つけるのは、こころのブレーキの**入口**です。原因を決めつけるものではありません。

## 流れ

1. **課題の明確化** — 取り組む領域を確認し（Step3 の取組領域が最初から選ばれています。「テーマを切り替える」で別の領域も選べます）、満足度がその点数の理由を書き出す（初期設定は3〜10個）
2. **変えられるか** — 書き出した課題ごとに、次の4つから選ぶ
   - ① 自分で変えられそう
   - ② 自分から働きかけることはできそう
   - ③ 今の自分では変えるのが難しそう
   - ④ 分からない
3. **何が変わればよい？** — ①②の課題について、3つの方向から見る
   - **持ち方**（Have）：持っている資源（知識・スキル・時間・お金・人脈など）
   - **なし方**（Do）：行動のしかた（習慣・伝え方・頼り方など）
   - **あり方**（Be）：ものごとの捉え方（考え方・思い込み・価値観・自己イメージなど）
4. **まとめ** — 整理した結果を見て、次のこころのブレーキ探索へ

## 大切にしたいこと

- ③④を選んでも大丈夫です。一旦保留にして、後のステップで取り上げます
- すべてが③④になったときは、その状況の中でも「自分でできそうなこと」を一緒に探します
- 「あり方」は良し悪しを決めるものではなく、Ai と一緒に探るための入口です
