## 2. 同意（consents）の方針

**A案（確定・2026-05-20）**

- フリー・有料を問わず、**利用規約 + プライバシーを1回**同意（`users/{uid}.consents`）。
- 7日間専用の二重同意（`startProgram7dConsents`・`/start-program/consent`）は**廃止**。
- 利用規約は**章立て**（共通／7日間スタートプログラム／気づきノート等）。プライバシーは**サービス全体で1本**。

### 2.1 Firestore

| フィールド | 説明 |
|------------|------|
| `consents.termsVersion` | 同意時の利用規約版（`terms.json` の `version` と一致） |
| `consents.privacyVersion` | 同意時のプライバシー版（`privacy.json` の `version` と一致） |
| `consents.acceptedAt` | 同意日時 |

詳細: [03_FIRESTORE_DATABASE_STRUCTURE.md](./03_FIRESTORE_DATABASE_STRUCTURE.md)（`users` / `consents`）

### 2.2 版更新と再同意

1. `public/legal/terms.json` または `privacy.json` の本文を更新する。
2. 再同意を求める場合は **`version` を新しい日付に変更**する（例: `2026-06-01`）。
3. デプロイ（Vercel では `public/` 変更も再デプロイが必要）。
4. 既存ユーザーは `consents` の版が古いため `/post-login` → `/consent` に誘導される。

**ローカルで同意フローをやり直す**: [04_TEST_ONBOARDING_CHECKLIST.md](./04_TEST_ONBOARDING_CHECKLIST.md) §1（`consents` フィールド削除）

## 4. JSON スキーマ（概要）

### 4.1 利用規約 `terms.json`

```json
{
  "version": "2026-03-18",
  "title": "利用規約",
  "sections": [
    {
      "id": "common",
      "title": "第1章　共通（全利用者に適用）",
      "paragraphs": ["第1条 …", "第2条 …"]
    }
  ]
}
```

- `sections[]`: 章ごと。`id` は任意（安定した識別子）。
- `paragraphs[]`: 段落の配列（1要素 = 1段落）。

### 4.2 プライバシー `privacy.json`

```json
{
  "version": "2026-03-18",
  "title": "プライバシーポリシー",
  "paragraphs": ["第1条 …", "第2条 …"]
}
```

### 5.3 Markdown → JSON の対応表（利用規約）

| §5.1 の見出し（`title`） | `sections[].id` |
|--------------------------|-----------------|
| 利用規約（ダミー条文） | `intro` |
| 第1章　共通（全利用者に適用） | `common` |
| 第2章　7日間スタートプログラム（フリーコース） | `start7d` |
| 第3章　気づきノート（スタンダード／プレミアム） | `kizuki` |
| 第4章　免責・準拠法（共通） | `misc` |

**JSON 化の手順（利用規約）**

1. §5.1 の **版**を `terms.json` の `version` にコピー
2. 各 `####` 見出しを `sections[].title` に、直下の段落（`json id` 行を除く）を `paragraphs[]` に分割
3. 対応表の `id` を `sections[].id` に付与
4. `/consent`・`/terms` で表示確認

**JSON 化の手順（プライバシー）**

1. §5.2 の **版**を `privacy.json` の `version` にコピー
2. 全文を上から順に `paragraphs[]` の各要素へ（1段落1要素）
3. `title` は「プライバシーポリシー」
