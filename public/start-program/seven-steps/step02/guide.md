# Step2：自分らしさを探る

Step1 の曼荼羅チャートで書いた「願望」と、そのとき選んだ分類（A/B/C/D）をもとに、あなたの**こころのアクセル**——興味・関心、価値観、得手・能力——を深掘りし、言葉にしていきます。

## 分類について（Step1 で実施）

- **A.** 興味・関心が強いから → Step2「興味」レーン
- **B.** 価値観に合っているから → Step2「価値観」レーン
- **C.** 得意・上手にできるから → Step2「得意・強み」レーン
- **D.** その他 → 深掘り対象外

## 興味レーンの流れ

1. **掘り下げ** — 願望ごとに「どこに興味があるか」を選ぶ（複数可・手追加可）
2. **まとめる** — 関心ピルを色分けし、グループに名前を付ける
3. **文にする** — キーセンテンスにする（述語選択＋行動を記入）

## 価値観レーンの流れ

1. **掘り下げ**
   - （任意）B 分類の願望から価値観を選ぶ
   - （**必須**）感動した出来事＋感情から Ai で価値観をリストアップ（最低 1 件）
2. **まとめる** — 価値観ピルを色分けし、グループに名前を付ける
3. **文にする** — 「大切にしている／守りたい」などでキーセンテンスにする

## 得意・強みレーンの流れ

1. **掘り下げ**
   - （任意）C 分類の願望から得意・強みを選ぶ
   - （**必須・どちらか1件以上**）他者からの言葉／自然とできた体験＋感情から Ai でリストアップ
2. **まとめる** — 色分けし、グループに名前を付ける
3. **文にする** — 「が得意だ／が強みだ／が自然にできる」などでキーセンテンスにする
