## 手順1：まず UI から復旧を試す（安全・推奨）

1. **Cursor を完全終了**（タスクバーのアイコンも終了）
2. Cursor を再起動
3. **`Ctrl+Shift+P`** を押す
4. **`Developer: Reload Window`** を実行
5. もう一度 **`Ctrl+Shift+P`** → **`Show Chat History`**（または `chat:` で検索）
6. 通常の **Chat** サイドバーで履歴を確認（**Agents** 画面ではなく）

これで戻ることがあります。まずここまで試してください。

---

## 手順2：バックアップ DB から復元する（手順1で戻らない場合）

アップデート前の状態が `state.vscdb.backup` に残っている可能性があります。

### 2-A. グローバル履歴の復元（チャット一覧全体）

1. **Cursor を完全終了**
2. エクスプローラーで次を開く：

```
%APPDATA%\Cursor\User\globalStorage
```

（実際のパス：`C:\Users\ineth\AppData\Roaming\Cursor\User\globalStorage`）

3. **必ずバックアップを取る**（上書き前に）：

```
state.vscdb          → state.vscdb.before-restore（リネーム）
state.vscdb.backup   → そのまま残す
```

4. 次を実行：

```
state.vscdb.backup をコピー
→ コピー先の名前を state.vscdb に変更
```

5. Cursor を起動 → **`Show Chat History`** で確認

**元に戻すとき：** `state.vscdb.before-restore` を `state.vscdb` に戻せば、復元前の状態に戻せます。

### 2-B. プロジェクト別 DB の復元（この manabiba プロジェクト専用）

同様に、プロジェクト用フォルダでもバックアップがあります（5/24 13:21 更新）。

```
%APPDATA%\Cursor\User\workspaceStorage\76e5ec15cd2011c3200ac8157f68f15d
```

手順は 2-A と同じです。

```
state.vscdb → state.vscdb.before-restore にリネーム
state.vscdb.backup → state.vscdb にコピー＆リネーム
```

**注意：** 2-A と 2-B の両方をやる場合は、**まず 2-A だけ**試し、ダメなら 2-B を試すのが安全です。
