## 1. 目的と範囲

### 1.1 目的

Step1〜4 で見出した **夢（望み）・自分らしさ（アクセル）・現状（満足度）・こころのブレーキ** をもとに、

1. 満足度が **8 以上** になった「なりたい自分（目標）」を描き、
2. それを **持ち方・なし方・あり方** の3方向で具体的に描き、
3. その目標が **自分らしさ** を満たしているかを評価し、
4. 目標と対比して **現在の自分** を改めて捉え直す。

前半の成果物は「**なりたい自分**」と「**現在の姿**」を並べて見える化したボード。後半（別紙予定）でタイムラインに落とす。

### 1.2 範囲

| 区分 | 内容 |
|------|------|
| 本紙（前半） | 目標を描く → 3方向で具体化 → 自分らしさ評価 → 現在の姿 → 見える化 |
| 後半（別紙） | いつまでに（達成時期・中間目標）、どの程度（評価指標）、タイムライン |
| 紙との対応 | WS7 の ①どのような状態（What state）＋ ④現在地の見える化。②いつまでに・③どの程度は後半へ |

## 3. 全体の流れ（前半）

```
① ふりかえりと目標  Step1〜4 の夢・自分らしさ・現状・ブレーキを振り返り、目指す満足度（8〜10）を決める
      ↓
② 3方向で描く       持ち方（結果）／なし方（行動）／あり方（自分らしさ）ごとに「目標の状態」を書き、
                    最後に全体を見渡して「目標の一文」を決める（AI がエモい案を提案）
      ↓
③ 自分らしさ評価    興味はあるか？／価値観は反映されているか？／強みが活かされているか？
      ↓ （満たしていなければ ② に戻って調整。進むことはできる）
④ 現在の姿          ②の各項目について「今の自分」を書く
      ↓
⑤ 見える化          現在（3）と目標（8）を3方向で並べたボード → 後半へ
```

フェーズ切替は Step3・Step4 と同じ上部ピル型ナビ（完了で ✓、前段完了で次が解放）。URL: `?pane=worksheet&phase=review|layers|fit|current|board`

| # | フェーズ名（案） | 解放条件 |
|---|------------------|----------|
| 1 | ふりかえりと目標 | Step4 完了（どれか1課題で気づき保存）かつ取組領域あり |
| 2 | 3方向で描く | 目指す満足度を決定済み |
| 3 | 自分らしさ | 3方向のすべてに目標の項目が1つ以上、かつ目標の一文が入力済み |
| 4 | 現在の姿 | 自分らしさの3問すべてに回答 |
| 5 | 見える化 | 目標の全項目に現在の姿が入力済み |

> 2026-10-13 決定（D2・D3）により、①で書く予定だった「目標の一文」と「達成した姿（状態）」は ② に移した。状態は3方向の項目に吸収し、一文は3方向を書き終えてから全体を見渡して決める。①は振り返りと目指す満足度の決定に絞る。

## 4. 画面仕様

### 4.1 ① ふりかえりと目標

構想図の左側（Step01〜04 → 夢・自分らしさ・現状・ブレーキ）を1画面で振り返り、目指す満足度を決める。

| 要素 | 内容 |
|------|------|
| 夢 | Step1 の取組領域の願い |
| 自分らしさ | Step2 の興味・価値観・強みの文 |
| 現状 | Step3 の満足度（例: 3/10）と、Step4 の課題（①②）。③④保留課題は §4.2.1 |
| ブレーキへの気づき | Step4 深掘りで保存した気づき（こころの働き・自分の言葉） |
| 目指す満足度 | 8〜10 から選択（既定 8）。現在 3 → 目標 8 の三角形で表示 |
| 問い | 「〔取組領域〕の満足度が 8 になったとき、あなたはどんな毎日を過ごしていますか？ 次の画面で3つの方向から描いていきましょう」 |

### 4.2 ② 3方向で描く（持ち方・なし方・あり方）

構想図下段の左右レイアウト（現状 ⇄ 目標）の「目標」列を埋める画面。

| 行 | 見出し（図の表記） | 問い（案） | 例（裕子さん） |
|----|--------------------|-----------|----------------|
| 持ち方 | 結果 | 目標を達成したとき、何を持っていますか？（資源・知識・つながり・環境） | パン作りの販売経験、地域の常連さん、週15時間の自分の時間 |
| なし方 | 行動 | そのとき、日々どんなふうに行動していますか？ | 月2回マルシェに出店、家族と家事を分担している |
| あり方 | 自分らしさ | そのとき、ものごとをどう捉えていますか？ | 「失敗しても試してみればいい」と思える、自分の経験に価値があると感じている |

- **初期表示**: Step4 で選ばれたタグを集計し、行ごとに「項目の入口」カードとして並べる（例: 持ち方「知識・能力・経験」→ 問い「どんな知識・経験を持っていますか？」）。項目は追加・削除できる。
- **あり方の行**: Step4 深掘りの「こころの働き」「自分の言葉」を参照表示し、「その働きと、どう付き合えている自分になっていたいか」を問う（ブレーキをアクセルに変える視点）。
- 各項目は「目標の状態」を1文で書く。AI がピル型で候補を出し、選んで編集できる（§6 AI-1）。
- 各行 1 件以上必須、上限 5 件。
- **目標の一文**（画面下部）: 3方向を書き終えたら「全体を見渡すと、なりたい自分をひとことで言うと？」を問う。AI が心に響く（エモい）目標案を 3 つ出し、選んで編集する（§6 AI-2）。必須・60字程度。
  - 例（裕子さん）:「10年の子育てで育てた力を、パンと笑顔に変えて地域に届けている私」

#### 4.2.1 ③④（保留）課題の扱い（D7 決定: A 参照のみ）

Step4 の「変えられるか」で ③今の自分では変えるのが難しそう／④分からない とした課題。Step4 では持ち方・なし方・あり方のタグを付けておらず、「後のステップで取り上げます」と案内している。

| 例 | 課題 | 区分 |
|----|------|------|
| 裕子さん | 住んでいる地域には、希望する時間帯で働ける求人が少ない | ③ |
| 康太さん | 会社の評価制度が数字中心で、自分が大事にしたいことと合っていない | ③ |
| 康太さん | 自分が本当は何を大事にしたいのか、まだ言葉にできていない | ④ |

選択肢:

- **A. 参照のみ**: ②の画面に「保留中の課題」として表示するだけ。目標の項目にはしない。
- **B. 取り込める**: 各課題に「目標に含める」ボタンを置き、本人が持ち方・なし方・あり方のどれかを選んで項目にする（例: 求人が少ない → 持ち方「在宅でもできる仕事の機会を持っている」）。
- **C. 見直してから取り込む**: 満足度 8 の自分から見て、もう一度「変えられるか」を問い直し、①②に変わったものだけ取り込む。

**決定（2026-10-13）: A 参照のみ。** ② の画面下部に「保留中の課題（参照）」として表示し、目標の項目にはしない。後半（タイムライン）でも参照として表示する。

### 4.3 ③ 自分らしさ評価

構想図右下「自分らしさが反映できるか → 評価する」。**これが反映されないと長続きしない**ことを画面で伝える。

| 問い | 参照 | 回答 |
|------|------|------|
| 興味はあるか？ | Step2 興味レーンの文 | ◎ とても／○ ある程度／△ あまり |
| 価値観は反映されているか？ | Step2 価値観レーンの文 | 同上 |
| 強みが活かされているか？ | Step2 強みレーンの文 | 同上 |

- △ がある場合: 「目標に〔興味／価値観／強み〕を取り入れるとしたら？」を表示し、② へ戻る導線と AI の調整案（§6 AI-3）を出す。**△ のままでも先へ進める**（D5 決定）。
- 3 問とも ◎○ なら「自分らしい目標です」と肯定のメッセージ。

### 4.4 ④ 現在の姿

構想図の「現状を認識」矢印（目標 → 現状）。② の各項目に対応させて「今の自分」を書く。

| 列 | 内容 |
|----|------|
| 目標の状態 | ② で書いた項目（表示のみ） |
| 今の自分 | 1文（必須）。Step3・Step4 の課題・深掘りから AI が下書き（§6 AI-4） |

- 違い（ギャップ）は後半で扱う（D6 決定）。

- 最初は曖昧でよいこと、後から直せることを明記する（紙 WS7 ④の趣旨）。

### 4.5 ⑤ 見える化（ボード）

構想図下段そのもの。

```
           現在（3）                 目標（8）
持ち方／結果   [今の自分 …]   ⇄   [目標の状態 …]
なし方／行動   [今の自分 …]   ⇄   [目標の状態 …]
あり方／自分らしさ [今の自分 …] ⇄  [目標の状態 …]
                     自分らしさ評価: 興味 ◎ / 価値観 ○ / 強み ◎
```

- 上部に目標の一文、満足度 3 → 8 の三角形。

## 6. AI の活用（案）

Step4 と同じく **AI は候補を出すだけで、決めるのは本人**。画面表示の前に先読みし、失敗時は固定の基本候補で回答できるようにする。

| ID | タイミング（先読み） | 入力 | 出力 | 使う画面 |
|----|----------------------|------|------|----------|
| **AI-1** 3方向の具体化 | Step5 を開いたとき（目指す満足度の変更時は再生成） | Step1 願い、Step2 自分らしさの文、Step3 満足度・気づき、Step4 タグ・課題・深掘りの気づき、目指す満足度 | 持ち方・なし方・あり方ごとの「目標の状態」候補 各 4〜6 件 | ② |
| **AI-2** 目標の一文（エモい案） | ② の3方向がそろったとき | ② の項目、Step1 願い、Step2 自分らしさ | 心に響く目標の一文 3 案 | ②下部 |
| **AI-3** 自分らしさ診断 | ② 保存後 | 目標の一文と項目、Step2 の文 | 3 問それぞれの見立てコメント＋△時の調整案 | ③ |
| **AI-4** 現在の姿の下書き | ② 保存後（AI-3 と同時） | ② の項目、Step3・Step4 の課題・深掘り | 項目ごとの「今の自分」案 | ④ |

- AI-1〜4 の 4 回を使う（D9: 自分らしさ診断も使う）。
- 「Ai更新」（言い換え）は 1 段階 3 回まで（Step4 D7 と同じ）。
- 前段を変更したら後段の候補を作り直し「選択肢を更新しました」を表示（Step4 D6 と同じ）。
- AI の実組込は Step4 と同様、最終段階の全体調整で詰める。モックはダミー応答（裕子さん・康太さんの例）。

## 11. 今回出す範囲（2026-10-28）

Step5 は、ここで一度止める。プロセスは次の3つ。URL の `phase` は `review` / `layers` / `summary`。

```
満足度設定 → 目標を描く → 持ち方をまとめる
```

| プロセス | phase | すること |
|----------|-------|----------|
| 満足度設定 | `review` | こころと状況の関係図で Step1〜4 を振り返り、現状より上かつ 10 までの目指す満足度を選ぶ |
| 目標を描く | `layers` | 持ち方だけを、課題ごとの問いで書く |
| 持ち方をまとめる | `summary` | 書いた持ち方を確認し、1〜2文にまとめ、実現時期を書く |

自分らしさ・現在の姿・見える化、および後半（違い・しるし・いつまでに・振れ幅・道のり）の画面コードは残すが、ナビには出さない（`unlocked` は常に false）。なし方・あり方は次のステップで扱う。

### 11.1 満足度設定

- 望む姿・自分らしさ・現在の姿・心のブレーキは、関係図のカードからモーダルで読む。
- 目指す満足度は現状より上。現状以下のセルは斜線で選べない。選んだ目標は ▼、現状は ▲。
- 狭い幅では関係図全体を縮小し、左右が切れないようにする。

### 11.2 目標を描く

- 左は「現在の自分」（Step4 の課題文。押しても開かない）。右の設定エリアは持ち方のカードだけ。
- カードを押すと「のぞむ姿」設定画面。課題ごとに、Step4 で選んだ項目の問いと入力欄だけを出す。
- AI の選択肢は出さない。裕子さん・康太さんの具体例を「○○さんの場合」で参照し、本人が書く。閉じると目標を描くに戻る。
- 持ち方の欄がすべて埋まると「持ち方をまとめる」へ進める。

### 11.3 持ち方をまとめる

進み方は次の3段。1 は問題がなければ省いてよい。

1. 設定した持ち方を「・」の箇条書きで確認する。整えるときは「編集」で、目標を描くときと同じ設定画面を開く。
2. 達成しやすさ・重要性・ワクワク感などの優先を考え、1から2文にまとめる。
3. 実現時期を自由に書く（〇年〇月、〇年〇月〇日、年ごろ、年末、年中旬など。西暦・元号どちらでもよい）。

「Aiでまとめてみる」は見出しの中に説明と Ai選択ボタン、その下に「・」付きの候補を出す。ボタンを押すまで候補は作らない。選ぶと目標欄に入り、あとから直せる。文末は「○○な私」にしない。

目標文と実現時期の両方が入ったときだけ、テーマ欄の `step05-context-goal` に次の2行を出す。

```
私は、〔実現時期〕までに、
　〔まとめた内容〕
```

完了（ピルの ✓）も、この2つがそろったとき。保存は `goal.statement`（内容）と `goal.expressionPeriod`（実現時期）。

### 11.4 データの持ち方

- 持ち方の1欄は、Step4 の課題（`reasonId`）× その課題で選んだタグ（`sourceTagId`）。`step05Progress` の `layersFilled` は持ち方の欄だけを見る。
- 参考例は `src/lib/startProgram/step05Examples.ts` が、具体例 JSON（裕子さん・康太さん）を読む。
- まとめ文の整形は `formatHaveSummary` / `toHaveContent`（`step05Constants.ts`）。
