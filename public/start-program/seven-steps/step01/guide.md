# あなたの「～したい」を活性化する

あなたの人生を「望む方向へ」進めるには、まずはあなた自身の“望み(～したい)”を正しく知ることが欠かせません。人は、普段の生活や仕事の中で

- 他人の期待
- 職場や家族の基準
- 一般社会（世の中）の価値観

の影響を受け続けています。そのため、多くの人は「～しなければ」を優先してしまい、本当は何を望んでいるのかを忘れてしまったり、望んでも叶うはずがないと諦めてしまったりしています。でも安心してください。望みを書くことは、あなたの人生に“方向性”を取り戻すための第一歩です。

## 望みを書くと、より、自分が何者であるかが分かってくる

望みの言語化は、次の変化を促します。

- 自分が何を求めているのかが明確になる
- やりたいことが自然と見えてくる
- 忘れてしまった、あるいは諦めてしまった望みを思い出す
- 行動のモチベーションが高まる

そして何より、望みは「あなたが何者であるか」を映し出す鏡として働きます。

## 人生には様々な領域がある

人生において、「仕事だけ」「お金だけ」「趣味だけ」といったように、「一つだけは満足しているのだけれども・・」のようにバランスが偏った生活では、幸せや充実感が損なわれてしまいます。

こころ道場のコーチングでは、以下の領域がある【ワークシート(WS1)：あなたの望む人生(8つの領域)】を使って人生を「全体で」見ることから始めます。これにより「偏りの発見」「望みの可視化」「バランスの良い人生設計」を見える化します。

### あなたの人生を構成する「8つの領域」

1. **キャリア・仕事** — 働き方、役割、スキル、仕事の喜び、仕事の成果
2. **お金・財産** — 収入・貯蓄・投資・安定性・豊かさ・金銭的自由
3. **健康・ウェルネス** — 体力、病気予防、運動、睡眠、メンタルの安定
4. **精神面・内面** — 心の平穏、自己肯定感、価値観、感情管理、心の成長
5. **学習・経験** — 新しい挑戦、知識、スキル、資格、自己成長
6. **趣味・芸術** — 楽しみ、創造性、余暇、自分を満たす活動
7. **人間関係・家族** — 家族、パートナー、友人、職場、温かいつながり
8. **社会貢献** — 地域活動、支援、伝承・育成、奉仕、影響力

## ワークシートへの記入のポイント

- **制限をかけない** — 今の能力・収入・年齢は一旦忘れてください。
- **「こうなったら嬉しい」を書く** — 小さなことでも構いません。ワクワクを基準に。
- **望みを書く** — 目標は後のステップで明確化できます。ここでは“願いそのもの”を大切にしてください。

### 書き方の例（1〜2行でOK）

- 「暖かくて豊かな人との関係性をもちたい」
- 「体を鍛えて、フルマラソンにでたい」
- 「ゴルフをとことん楽しみたい」
- 「新しい商品を開発してヒットさせたい」
- 「バンドを組んでメジャーデビューしたい」
- 「世界一周旅行をしたい」

## 最後に人生の中心目標を書く

領域の書き出しが終了したら、総括してどんな自分になりたいかを書いてみます。書かなくても構いません。「私は、こんな人間になりたい」を書いてみます。
