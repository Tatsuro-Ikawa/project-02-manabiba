# Step2 興味レーン仕様（P0〜P2）

最終更新: 2026-09-14

本ドキュメントは Step2「あなたはだれ？」のうち **興味・関心レーン** の正本仕様です。  
価値観・得意・強みは興味レーン実装後に別途検討します（共通骨格は揃える想定）。

関連: [04_START_PROGRAM_SEVEN_STEPS_SPEC.md](./04_START_PROGRAM_SEVEN_STEPS_SPEC.md)

---

## 1. 目的

Step1 曼荼羅で入力した願望のうち、動機分類 **A（興味・関心）** の項目を深掘りし、  
「どこに興味があるか」→ 横断グルーピング → キーセンテンス、として **こころのアクセル** を言語化する。

## 3. Step1 との接続

| 項目 | 仕様 |
|------|------|
| 分類タイミング | Step1 願望入力時に A/B/C/D を必須選択 |
| Step2 興味リスト | `motivation === 'interest'` のエントリのみ |
| 中心目標 | 分類対象外。文脈表示のみ可 |
| D（その他） | Step2 深掘り対象外 |

### 認識の整理（確定）

- **掘り下げ**: 領域 → 願望 →「どこに興味があるか」（ピル）の紐づけを表示  
- **まとめる**: 選択済み興味ピルを **横断フラット化** して色分け（横断タグ）

## 4. データモデル

```typescript
/** Step1 既存 */
type MandalaEntry = {
  id: string;
  text: string;
  domainId: MandalaDomainId;
  motivation?: 'interest' | 'values' | 'strength' | 'other';
  // …
};

/** 願望ごとの関心候補（AI or 手動） */
type InterestOption = {
  id: string;
  wishEntryId: string;
  label: string;          // 全文
  source: 'ai' | 'manual' | 'dummy';
  selected: boolean;
};

/** まとめる単位 = 選択済みピル（横断） */
type InterestTag = {
  id: string;             // = InterestOption.id（選択されたもの）
  wishEntryId: string;
  label: string;
  colorId?: GroupColorId; // まとめる①
};

type GroupColorId = 'red' | 'yellow' | 'green' | 'cyan' | 'blue' | 'purple';

type InterestGroup = {
  colorId: GroupColorId;
  title: string;          // まとめる②
  comment?: string;       // 本人メモ
  tagIds: string[];
};

type KeySentence = {
  groupColorId: GroupColorId;
  interestPhrase: string; // 興味を示す言葉（グループタイトル自動投入可）
  predicate: 'interest' | 'like' | 'custom'; // 述語（下記）
  customPredicate?: string;
  actionPhrase: string;   // 行動・選択・ふるまい
};
```

### キーセンテンス述語（P1・確定方針）

テンプレは編集可。述語は次から選択＋自由編集:

| id | 表示例 |
|----|--------|
| `interest` | 私は【興味】**に興味がある**。だから【行動】のだ。 |
| `like` | 私は【興味】**が好きだ**。だから【行動】のだ。 |
| `custom` | 私は【興味】**（自由述語）**。だから【行動】のだ。 |

グループごとに 1 文。空でも次へ進める。推奨上限 **3 件程度**（最大 5）。

## 5. 掘り下げ（P0）

### 5.1 リスト画面

- 興味分類の願望をカード一覧
- 各カード: 番号、願望文、領域ピル、選択済み興味の短縮ピル（約 5 文字 truncate）
- カードクリック → モーダル

### 5.2 モーダル

- 対象願望を表示
- 「どこに惹かれますか？」複数選択可
- `+追加` で自由記入（手動候補）
- **Ai候補を取得** ボタン（P0: ダミー JSON から該当願望の候補を注入。本番 AI は P2）
- 前へ / 次の願望へ / 閉じる

### 5.3 AI 候補（フェーズ）

| Phase | 挙動 |
|-------|------|
| **P0** | 実 AI なし。ダミーファイル or モーダル「Ai候補を取得」で候補投入。手追加のみでも完了可 |
| **P2** | Step1 で動機=興味で保存時に非同期生成。編集時は作り直し。失敗時はモーダルで再取得 |

固定の汎用候補リストは **採用しない**（願望内容依存のため）。

### 5.4 完了条件

興味願望すべてに **1 つ以上** のピル選択。未完了でも価値観カードへ遷移可（バッジ表示）。

## 6. まとめる／文にする（実装済）

| 画面 | 仕様 | 状態 |
|------|------|------|
| まとめる① | 選択ピルをフラット一覧。6 色で色分け。未色分けは「まとめる」時に「その他」へ。Aiで分類は P2（スタブ） | **実装済** |
| まとめる② | 色ごとにグループ。タイトル命名。**ドラッグ＆ドロップ**でグループ間移動。コメント=本人メモ | **実装済** |
| 文にする | グループごとキーセンテンス。タイトル自動投入。述語選択＋全文編集可。空でも次へ可 | **実装済** |

色: 最大 6。推奨グループ数 3〜5。まとめる完了目安: **2 色以上** かつ各グループにタイトル。

### 操作（まとめる①）

1. 興味ピルを選択（複数可）
2. パレットの色をタップ → 選択中ピルに色を適用
3. 「元に戻す」で色分け履歴を1つ戻す
4. 「まとめる」で②へ（未色分けは「その他」）

### 操作（まとめる②）

1. 各色カードのタイトルを入力
2. 「コメント」で本人メモ（任意）
3. 項目を**ドラッグ＆ドロップ**して別グループへ移動
4. 「色分けに戻る」で①へ

### 操作（文にする）

1. グループごとに「興味を示す言葉」（タイトル自動投入・編集可）
2. 述語を選択（に興味がある／が好きだ／自由）
3. 「行動・選択・ふるまい」を記入
4. プレビューで完成文を確認。空欄でも次へ可（目安 1〜3 件、最大 5 グループ）

## 7. ローカル永続化（P0）

| キー | 内容 |
|------|------|
| `startProgram.sevenSteps.step01` | 曼荼羅（既存） |
| `startProgram.sevenSteps.step02.interest` | 興味レーン（options / tags / groups / sentences / UI 状態） |
