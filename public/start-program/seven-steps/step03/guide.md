# Step3：満足度をみて、取組む領域を決める

Step1 で描いた理想の自分（8つの領域）に対し、**いまの満足度**をつけ、レーダーでバランスを眺め、**最初に取り組む領域を1つ**決めます。

「なぜその点数なのか」やこころのブレーキは、領域を決めたあとの **Step4** で扱います。

## 流れ

1. **満足度（0〜10）** — 各カードで点数をつける
2. **レーダーチャート** — 8領域のバランスを俯瞰する（気づきメモは任意）
3. **取組領域** — 気になる領域を最大4つ挙げ、重要度・ワクワク・変化可能性で絞り、1つ決める

## 選ぶときのヒント

- 満足度が低く、整えると人生のバランスがよくなりそうな領域を優先
- すでに高い領域だけを伸ばすより、凹みを整えると楽になることが多い
- 迷ったら「いま一番気になるところ」でよい（あとから変えられます）
