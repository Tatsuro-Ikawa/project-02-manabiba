Step1 曼荼羅で動機分類 **C（得意・強み）** とした願望と、**必須の付加ソース**から、

## 3. 掘り下げ

### A. 願望ベース（件数は Step1 依存）

- C 分類の願望ごとに得意・強みピルを選択（複数可）
- Ai 候補（P0 はダミー）＋手追加

### B. 他者からの言葉 ／ C. 自然とできた体験（付加ソース）

両方入力可能。**どちらか最低 1 件完了が必須**（C案）。

各件の流れ:

1. 場面を書く（他者の言葉／自然とできた体験）
2. そのときの感情・気持ち・感覚
3. Ai で得意・強みリスト → 選択／手追加

完了条件: 場面・感情が非空 かつ ピルを 1 つ以上選択。

掘り下げ完了: （C 願望がある場合はすべて選択済）かつ 付加ソース完了 ≥ 1。

## 4. まとめる・文にする

興味／価値観と同 UI（色分け・色を外す・命名・DnD）。

### キーセンテンス

```
私は、【得意・強み】が得意だ／が強みだ／が自然にできる。だから、【ふるまい】のだ。
```

述語: **が得意だ**／**が強みだ**／**が自然にできる**／自由入力。
