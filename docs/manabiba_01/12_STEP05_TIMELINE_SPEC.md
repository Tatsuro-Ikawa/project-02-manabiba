## 1. 目的と範囲

### 1.1 目的

前半で描いた「なりたい自分（目標）」と「今の自分（現在地）」の **違いを、いつまでに、どのように詰めていくか** を決める。

1. 目標と現在の **違い（ギャップ）** を言葉にする
2. 目標にたどり着いたと分かる **到達のしるし** を決める
3. **いつまでに**（達成時期と段階・節目）を決める
4. うまくいかない時期を前提にした **振れ幅** を持たせる
5. これらを **道のり（タイムライン）** として見える化する

### 1.2 範囲と役割分担

| 区分 | 決めること | 仕様書 |
|------|------------|--------|
| Step5 前半 | なりたい自分（3方向）・目標の一文・自分らしさ評価・現在の姿 | 11 |
| **Step5 後半（本紙）** | 違い、到達のしるし、達成時期・段階・節目の姿、振れ幅、道のり | 12 |
| Step6 | 違いを縮める行動（仮説）、行動のめやす（段階ごと）、阻害が起きたときの乗り越え策 | 別紙予定 |
| Step7 | 行動宣言（アファメーション）でコミットメントを固める | 別紙予定 |
| 実施（気づきノート） | 実行の記録・確かめ・立て直し（PDCA）、スケジュール管理 | 13 |

> 行動のめやす（行動の量）は、行動を決める Step6 で設定する。Step5 後半は「いつまでに、どんな状態になっているか」までに留める。

## 2. 言葉の置き換え（UX ガイドライン）

ビジネスの用語（KGI・KPI など）は画面に出さない。計画づくりの枠組みとしては同じだが、道場では **自分らしさを原動力** にする。前半の「持ち方・なし方・あり方」は、そのまま指標の構造に対応している。

| 一般的な用語 | 道場での言い方 | 利用者への問い | 主に対応する方向 | 決める場所 |
|---|---|---|---|---|
| KGI（最終指標） | **到達のしるし** | 目標にたどり着いたと、何で分かりますか？ | 持ち方（結果） | Step5 後半 |
| 中間目標・マイルストーン | **節目の姿** | ○か月後、どこまで来ていたら順調ですか？ | 3方向とも | Step5 後半 |
| KPI（行動の量） | **行動のめやす** | どのくらいやれたら「やれた」と言えますか？ | なし方（行動） | Step6 |
| KPI（成果の兆し） | **手応えのしるし** | 行動が効いてきたと、何で気づけそうですか？ | あり方・持ち方 | Step5 後半（しるしの一部） |
| ドライブ要因 | **らしさ** | 自分らしく取り組めましたか？ | 自分らしさ | 前半の評価を引き継ぐ |
| 実行率 | **やれた** | — | — | 実施段階 |
| 進捗・達成度 | **近づいた** | — | — | 実施段階 |
| リスク・バッファ | **振れ幅・余白** | うまくいかない時期があるとしたら、いつ頃ですか？ | — | Step5 後半 |

表現の原則:

- 「未達」「遅延」「失敗」「KPI」などの語は使わない。遅れは「少しゆっくり」「見直しどき」と表す。
- 赤字や警告色で遅れを強調しない。
- 計画の見直しは失敗ではなく、**予定された手順** として示す。

## 3. 設計の考え方

### 3.1 習熟は「予測」ではなく「段階」で持つ

「今の力のまま、この期間で達成できる」と計画すると、習熟で行動の質や量が上がることが計画に表れない。一方、習熟の度合いを予測して計画すると、本人には伸び方を予測できず、外れたときに失敗体験になる（それ自体がブレーキの引き金になる）。

そこで、期間を **3つの段階** に分け、段階ごとにめやすと手応えを少しずつ上げる。

| 段階 | ねらい | 行動のめやす（Step6） | 期待する手応え |
|------|--------|------------------------|----------------|
| ① なじむ（最初の 4 週） | 今の力を知る「ためし期間」 | 小さく、続けられる量 | 「やれた」が続く |
| ② 広げる | 量や質を上げる（習熟） | 少し上げる | 手応えのしるしが動き始める |
| ③ 根づかせる | 到達のしるしに届く | 安定して続ける | 節目の姿・到達のしるしに届く |

- ① の終わりに **めやすと期間を見直す場面** を必ず設ける。最初の計画は粗くてよい（紙 WS8「行動は仮説」、WS7④「現在の自分は行動を始めてから気づく」と同じ考え方）。
- ① の 4 週は、気づきノートの 28 日トライアルと重なるようにする（[13](./13_PLAN_JOURNAL_INTEGRATION_SPEC.md) §7）。

### 3.2 評価の3つの軸

実施段階では、次の3つを分けて見る。

| 軸 | 見るもの | 主な記録元 |
|----|----------|------------|
| **やれた** | 行動をどのくらい実行できたか | 晩の行動ごとの記録 |
| **近づいた** | 実行が成果（しるし）に結びついたか | 週・月のしるしの記録 |
| **らしかった** | 自分らしく取り組めたか（続けられるか） | 晩・週の自己評価 |

### 3.3 やれた × 近づいた の4分類

| | 手応えあり | 手応えなし |
|---|---|---|
| **やれた** | 続ける／次の段階へ | 行動の中身を見直す（仮説の修正） |
| **やれなかった** | 行動を軽くして続ける。状況の変化を確認 | ブレーキや負荷を見直す（Step6 の乗り越え策・Step7 の行動宣言へ） |

「行動しなかった問題」と「行動の選び方の問題」を分けることで、フィードバックの内容が決まる。「やれたけれど、らしくない（苦しい）」は続かなくなる予兆として扱う。

## 4. 全体の流れ（後半）

前半の ⑤ 見える化 の「このなりたい自分で進む」から続く。

```
⑥ 違いを見る        目標と今の自分の違いを書き、各方向から「重点」を 1 つ選ぶ
      ↓
⑦ 到達のしるし      重点ごとに「たどり着いたと分かるしるし」を決める（全体で 3〜5 個）
      ↓
⑧ いつまでに        開始日・達成時期（幅つき）・3 段階・節目の姿
      ↓
⑨ 振れ幅            忙しくなりそうな時期・余白の週・ブレーキが出そうな節目・状況の阻害
      ↓
⑩ 道のり            タイムラインで見える化 → 「この道のりで進む」で Step5 完了 → Step6 へ
```

フェーズ切替は前半と同じ上部ピル型ナビ。前半の 5 フェーズに続けて表示するか、前半・後半でナビを分けるかは D11。

| # | フェーズ名（案） | phase | 解放条件 |
|---|------------------|-------|----------|
| 6 | 違いを見る | `gap` | 前半完了（見える化で確定） |
| 7 | 到達のしるし | `markers` | 全項目に違いが記入済み、各方向で重点を 1 つ選択済み |
| 8 | いつまでに | `period` | しるしが 3 個以上（重点 3＋満足度）、全しるしに今の値・目指す値あり |
| 9 | 振れ幅 | `risk` | 開始日・達成時期・3 段階の日付・各節目の姿が決定済み |
| 10 | 道のり | `timeline` | 振れ幅の画面を確認済み（入力は任意） |

## 5. 画面仕様

### 5.1 ⑥ 違いを見る

前半の各項目を「目標 ⇄ 今の自分」で並べ、その **違い** を 1 文で書く（紙 WS7 ④のギャップ）。違いは「成長の伸びしろ」と表現する。

| 列 | 内容 |
|----|------|
| 目標の状態 | 前半 ② の項目（表示のみ） |
| 今の自分 | 前半 ④ の記入（表示のみ・ここで修正も可） |
| 違い | 1 文（必須）。AI が下書き（§7 AI-5） |
| 重点 | 各方向から 1 つ ◎ を選ぶ（必須）。「ここが変わると、全体が動きそう」なもの |

- 項目が多い場合でも、しるしを付けるのは **重点の 3 つ** に絞る（負担が増えると、それ自体が止まる原因になるため）。
- 重点以外の項目は、道のりの画面で参照として表示する。

例（裕子さん）:

| 方向 | 目標 | 今 | 違い |
|------|------|----|------|
| 持ち方 ◎ | パン作りの販売経験があり、自分の腕に自信を持って話せる | 10年のブランクがあり、自分に何ができるのか自信がない | 自分のパンを「売れるもの」として人に示した経験がない |
| なし方 ◎ | 月2回マルシェに出店し、お客さんの声を聞いている | 出店してみたい気持ちはあるが、調べるだけで終わっている | 申し込みという最初の一歩を踏み出していない |
| あり方 ◎ | 「失敗しても試してみればいい」と思える | 「失敗してみじめな姿をさらすのが怖い」と感じて立ち止まりがち | 失敗を「試した証拠」と受け止める経験が少ない |

### 5.2 ⑦ 到達のしるし

重点ごとに「たどり着いたと分かるしるし」を決める。加えて、取組領域の **満足度**（今 → 目指す満足度）を全体のしるしとして自動で置く。

| 要素 | 内容 |
|------|------|
| しるしの名前 | 1 文（例：月の出店回数） |
| 種類 | **回数**（例：月 2 回）／**10段階**（自己評価）／**できた・まだ**／**ことば**（例：「家族に頼めた」と言える） |
| 今の値 | 種類に応じて入力（ことばの場合は「今の状態」1 文） |
| 目指す値 | 同上 |
| 確かめる頻度 | 毎週／毎月 |
| 区分 | 到達のしるし（最終）／手応えのしるし（途中で動き始めるもの） |

- 数で表せないものを無理に数値化しない。内面の目標（例：康太さん）は **10段階** と **ことば** を基本にする。
- しるしは全体で **3〜5 個**（満足度を含む）。
- AI が重点ごとにしるしの候補を出す（§7 AI-6）。

例:

| 人 | 重点 | しるし | 種類 | 今 → 目指す | 頻度 |
|----|------|--------|------|-------------|------|
| 裕子さん | 全体 | 仕事・キャリアの満足度 | 10段階 | 3 → 8 | 毎月 |
| | 持ち方 | 自分のパンを人に勧められる自信 | 10段階 | 3 → 7 | 毎月 |
| | なし方 | 月の出店回数 | 回数 | 0 → 2 | 毎月 |
| | あり方 | 「試してみよう」と思えた日（週あたり） | 回数 | 0 → 4 | 毎週 |
| 康太さん | 全体 | 精神・内面の満足度 | 10段階 | 3 → 8 | 毎月 |
| | 持ち方 | 休日の休まり度 | 10段階 | 3 → 7 | 毎週 |
| | なし方 | 寝る前のふり返りノート（週あたり） | 回数 | 0 → 5 | 毎週 |
| | あり方 | 評価に振り回されなかった度 | 10段階 | 3 → 7 | 毎週 |

### 5.3 ⑧ いつまでに

| 要素 | 内容 |
|------|------|
| 開始日 | 既定は翌週の初日。日付で持つ（週の始まりは利用者設定に従って表示） |
| 達成時期 | 3か月／6か月／1年／日付指定。**幅** を持たせる（例：6〜8 か月）。幅の初期値は期間の 2〜3 割 |
| 段階 | なじむ（開始から 4 週・固定）／広げる／根づかせる。②③の境目は既定で残り期間を 6:4 に分け、利用者が調整できる |
| 節目の姿 | 各段階の終わりに「ここまで来ていたら順調」を 1 文＋しるしの期待値で書く。AI が下書き（§7 AI-7） |
| 見直しの日 | ① なじむ の終わりに自動で置く（めやす・期間を見直す） |

例（裕子さん・6 か月、幅 6〜8 か月）:

| 段階 | 期間 | 節目の姿 | しるしの期待値 |
|------|------|----------|----------------|
| なじむ | 11/2〜11/29 | 家族と分担して、週 5 時間のパン作りの時間を確保できている | 自信 4、「試してみよう」週 1 |
| 広げる | 11/30〜2/28 | マルシェに 1 回出店し、お客さんの感想を聞けた | 出店 1、自信 5、「試してみよう」週 2 |
| 根づかせる | 3/1〜4/30 | 月 2 回の出店が続き、常連さんができ始めている | 出店 2、自信 7、満足度 8 |

### 5.4 ⑨ 振れ幅

うまくいかない時期がある前提で、計画に余白を持たせる。**入力は任意** だが、問いかけで考えるきっかけを作る。

| 要素 | 内容 | 引き継ぎ先 |
|------|------|------------|
| 忙しくなりそうな時期 | 期間と理由（例：子どもの冬休み、決算期）。その期間は行動のめやすを下げる予定にする | Step6（めやすの調整）・実施（遅れ判定から除外） |
| 余白の週 | 各段階の終わりに 1 週の余白を置く（既定 ON） | 実施（遅れ判定） |
| ブレーキが出そうな節目 | Step4 の深掘りで選んだ「場面」と節目を照らし合わせ、目印を付ける（例：「応募しようと考えた時」→「初めて出店を申し込む前」） | Step6（乗り越え策の入力） |
| 状況の阻害 | 前半の保留中の課題（③④）を参照表示し、計画に影響しそうなものに印を付ける（D7=A のため目標の項目にはしない） | Step6（状況の阻害として別枠） |

- 問い（案）:「この期間で、うまくいかない時期があるとしたら、いつ頃ですか？」「Step4 で見つけた〔場面〕は、道のりのどこで出てきそうですか？」
- AI がブレーキの出そうな節目を提案する（§7 AI-7 に含める）。

### 5.5 ⑩ 道のり（タイムライン）

| 表示 | 内容 |
|------|------|
| 上部 | 目標の一文、満足度 今 → 目標、達成時期（幅） |
| 横軸 | 開始日〜達成時期（最長）。月の目盛り |
| 段階の帯 | なじむ・広げる・根づかせる（色分け）、見直しの日 |
| 節目 | 各段階の終わりに節目の姿 |
| しるしの予定線 | しるしごとに、今の値 → 節目の期待値 → 目指す値の線と幅 |
| 振れ幅 | 忙しい時期（網掛け）、余白の週、ブレーキの目印 |
| 参照 | 重点以外の項目、保留中の課題 |

- 「この道のりで進む」で Step5 完了 → Step6（行動を決める）へ。
- 計画は Step7 まで終えた時点で「確定」し、サーバーに保存する（[13](./13_PLAN_JOURNAL_INTEGRATION_SPEC.md) §3）。それまではスタートプログラムの下書きとして持つ。
- スマホでは縦のタイムライン（上から下へ段階が進む）に切り替える。

## 6. 実施段階への引き継ぎ（要約）

実施段階の詳細は [13](./13_PLAN_JOURNAL_INTEGRATION_SPEC.md)。本紙で決めたものは次のように使われる。

| 本紙で決めたもの | 実施段階での使われ方 |
|------------------|----------------------|
| 到達のしるし・手応えのしるし | 週・月に値を記録し、予定線と比べる（近づいた） |
| 段階・節目の姿 | 節目の振り返り。段階が進むと Step6 のめやすも上がる |
| 見直しの日 | ① の終わりに、めやす・期間の見直しを促す |
| 忙しい時期・余白の週 | 遅れ判定で考慮する（幅の内側の遅れは「順調」） |
| ブレーキの目印 | 節目が近づいたら、Step6 の乗り越え策を朝に表示する |

## 7. AI の活用（案）

前半（AI-1〜4）に続く番号。AI は候補を出すだけで、決めるのは本人。モックはダミー応答。

| ID | タイミング | 入力 | 出力 | 使う画面 |
|----|------------|------|------|----------|
| **AI-5** 違いの下書き | ⑥ を開いたとき | 前半の項目（目標・今）、Step4 の課題・深掘り | 項目ごとの「違い」案 | ⑥ |
| **AI-6** しるしの候補 | ⑦ を開いたとき（重点を変えたら作り直す） | 重点項目、取組領域、目指す満足度 | 重点ごとのしるし候補 3 件（種類・今・目指す値つき） | ⑦ |
| **AI-7** 節目とブレーキの目印 | ⑧ で期間を決めたとき | しるし、段階の日付、Step4 の場面・こころの声 | 節目の姿の下書き、ブレーキが出そうな節目の候補 | ⑧⑨ |

- 「Ai更新」は 1 段階 3 回まで（前半と同じ）。
- 前段を変更したら後段の候補を作り直し「更新しました」を表示（前半と同じ）。

## 8. データモデル（案）

Step5 後半の入力は、前半と同じ Step5 のストア（テーマ＝取組領域ごと）に **計画の下書き** として持つ。要素には最初から変わらない ID を付け、Step7 の確定時に [13](./13_PLAN_JOURNAL_INTEGRATION_SPEC.md) の `Plan` に写す。型の正本は 13 の 3 章。

```typescript
type Step05PlanDraft = {
  gaps: { itemId: string; gap: string }[];          // 前半の Step05Item.id に対応
  focusItemIds: Record<'have' | 'do' | 'be', string | null>;  // 重点
  markers: PlanMarker[];                            // 13 §3.3
  period: {
    // 13 §3.3 の Plan.startDate / targetDate / targetDateLatest に写す
    startDate: string;                              // YYYY-MM-DD（JST）
    targetDate: string;                             // 達成時期（標準）
    targetDateLatest: string;                       // 幅の最長
  };
  stages: PlanStage[];                              // 13 §3.3（なじむ／広げる／根づかせる）
  busyPeriods: PlanBusyPeriod[];                    // 13 §3.3
  bufferWeekPerStage: boolean;                      // 余白の週
  brakeMarks: { stageId: string; step04ReasonId: string; scene: string; note: string }[];
  situationMarks: { step04ReasonId: string; note: string }[];   // 保留中の課題
  timelineConfirmedAt: number | null;               // ⑩ 完了
  ai: { gaps; markers; milestones };                // AI-5〜7（AiSlot）
};
```
